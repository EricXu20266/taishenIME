## 一、词库优先级分层模型（V0.5.5 核心）

**设计原则**：先定义词库优先级，输入拼音后按优先级**逐层 pick**——高优先级词库先取，
取不满才下沉到低优先级。低层级永不插队，不做跨层混排。

| 层级 | 词库 | 内部排序 | 规模 | 示例 |
|------|------|----------|------|------|
| **P1** | 用户词库 | 热(7天内高频) > 温 > 过期 | 动态学习 | 泰深（ts 学过） |
| **P2** | 常用词库 common | 人工 rank 行序 | 568 条 | 微博/我们/测试/好的 |
| **P3** | 系统词库 system | 词频降序（维基语料） | 38.1 万 | 微波/我们仨/侧室 |
| **P4** | 领域词库 domains | 热度 > 词长 > 原序 | 16.9 万 | 侧视(astronomy)/之卦 |
| **P5** | 联想兜底 | 纠错/模糊/简拼/组合 | — | 我们测试(锚定拆分) |

**pick 规则**：
1. 输入拼音 → 各层分别查自己的索引
2. 按 P1→P5 顺序逐层取词：P1 取完才轮到 P2，P2 取完才轮到 P3……
3. 每层内部：先精确匹配（pinyin == key）再前缀扩展
4. 词长匹配（输入 N 音节 → N 字词先出）作为引擎层兜底（`apply_word_len_match`）
5. 高频专名（微博/微信/抖音等）**进 P2 common**——专名本质是常用词，
   不再需要领域词前置特例（V0.5.2 的 domain_exact_short 降为 P4 内部排序）

**关键效果**：
- `ceshi`：P3「测试」→ P4「侧视」→ 测试永远第 1
- `women`：P3「我们」→ P4「我们是冠军」→ 我们第 1
- `weibo`/`wb`：P2「微博」→ P3「微波/未必」→ 微博第 1（V0.5.2 效果保留且更干净）
- `zg`：P3「中国」→ P4「之卦」→ 中国第 1

## 二、引擎层完整流程（query_all，engine/src/lib.rs）

### 第 1 步：特殊模式早退
`v` 符号 / `c` 计算器 / `u` 拆字 / `r` 数字大写 / `U` Unicode / 双拼 / 组词模式 —— 各自独立出候选，**不进入**拼音主流程。

### 第 2 步：日期简码早退
`rq/sj/xq/nl/dt/ts/rqzh/rqen` 精确命中 → 日期候选（用户词简拼命中时让位）。

### 第 3 步：主查询（按顺序追加，去重）
| 顺序 | 来源 | 函数 | 触发条件 |
|------|------|------|----------|
| 1 | 分层整词/前缀查询 | `query()`（P1→P4） | 无条件 |
| 2 | 快捷短语 | 内置短语表 | 简码精确命中，插在用户词后 |
| 3 | 分层简拼补充 | `query_short()`（P1→P4） | 无条件（声母索引） |
| 4 | 混合简拼（全拼前缀+声母后缀） | `query_mixed()` | 候选 < 40 |
| 5 | 缩写+全拼（声母前缀+全拼后缀） | `query_abbrev_full()` | 候选 < 40 |
| 6 | 模糊音变体 | `fuzzy_variants()` | **仅完整拼音** |
| 7 | 拼写纠错（rime derive 规则） | `correction::spelling_variants` | 候选 < 5 |
| 8 | 多打字母容错 | `deletion_variants` | 候选 < 5 |
| 9 | 智能纠错（键位相邻） | `correction_variants` | **仅完整拼音** 且候选 < 40 |
| 10 | 错音错字提示 | `mistake::lookup` | 仅完整拼音 且候选 < 5 |
| 11 | 逐音节整词组合 | `query_combo()` | **仅非完整拼音** 且候选 < 40 |
| 12 | 逐音节拼接联想 | `combo_guess()` | **仅非完整拼音** 且候选 < 40 |
| 13 | 词库锚定拆分组词 | `phrase_group_guess()` | 候选不足一页（P5 兜底） |

### 第 4 步：收尾
14. 白话文长句过滤（>10 字丢弃，用户短语除外）
15. 截断到 max_pages 页
16. 自然语言日期追加（"日期/时间/年份"）
17. 英文混输追加（恒在末尾）
18. 置顶候选 pin_map 提到最前
19. `apply_context_boost`：上下文搭配前置（前文关联）
20. `apply_word_len_match`：词长匹配分区（输入 N 音节 → N 字词占前 4 位）
21. `apply_sort_mode`：单字/长词分区（用户显式开启）
22. 单字母输入（1 字符）只留单字候选

> V0.5.5 删除：`apply_long_word_filter`（长词提前，方向反）、`apply_domain_boost`（领域热度前置，分层后冗余）、`SYSTEM_HIGH_FREQ` 阈值（混排补丁）、`phrase_guess`（音节拼接怪词）。

### query() 内部（词库层，V0.5.5 分层）
精确层 + 前缀层都按 P1→P4 顺序逐层取词：
- P1 用户词（热 > 温 > 过期）
- P2 common（rank 行序）
- P3 system（词频降序）
- P4 domain（`push_domain_sorted`：精确优先 > 词长短 > 热度 > 原序）

## 三、实测复现（修复前，2026-08-09）

| 输入 | 修复前候选 | 问题 |
|------|----------|------|
| wo | 我 / 握 / 窝 / 卧 / 我国 | ✅ 正确 |
| women | **我们是冠军** / 我们 / 我们仨 / **我們的出口** / **我們的奇蹟** | ❌ 短句抢第 1；繁体混入 |
| ceshi | **测试用例** / **側視** / 测试 / 侧室 / 侧视 | ❌ 4 字抢第 1；繁体 |
| womenceshi | **我们测是** / 我们测式 / … | ❌ phrase_guess 拼接怪词 |
| xihuan | **喜欢编程** / 喜欢 / … | ❌ 4 字抢第 1 |
| zg | 之卦 / 只改 / 找个 / …（无中国） | ❌ 领域词压常用词 |

**根因**：① 词库数据混入繁体（维基繁体词条直接入库）② phrase_guess 无条件
音节拼接 ③ 领域词前置 + long_word_filter 长词提前 + 词频排序不约束词长，
三级叠加导致短句/领域词压过常用词。
