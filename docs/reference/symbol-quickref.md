> 关联 SPEC：docs/modules/symbol-mode/SPEC.md

## 双模式总览

泰深输入法的符号输入兼容**两种模式**，统一走 `v` 前缀入口：

| 模式 | 触发 | 适用人群 | 特点 |
|------|------|---------|------|
| **数字模式** | `v` + 数字（`v1`~`v9`） | QQ 拼音老用户 | 数字固定分类，不记码，肌肉记忆直达 |
| **分类码模式** | `v` + 拼音缩写（`vbd`/`vjt`） | rime/雾凇 用户 | 183 分类全量，精确直达任意符号 |

**交互铁律**（两模式共用一套交互）：
- 按 `v` → 候选窗立即显示 `v` 单字 + 常用热门符号（即时反馈）
- **v 前缀时数字键 = 分类导航**（v1-v9）；选热门符号用**空格**（首个）/ 鼠标 / 翻页
- 分类候选出现后（`v1`/`vbd` 已输完）**数字键恢复正常选词**
- 双拼模式下 v 是 zh 声母，符号模式自动排除（不误触）

## 四、常用流程示例

```
v           → 候选：[v, →, ←, ↑, ↓, …] 即时反馈（空格选 v，鼠标选符号）
v + 空格    → 上屏 v 字母（中文模式输出字母免切英文）
v + 数字    → 分类导航：v1 序号 / v2 数学 / v4 箭头 …
v + 分类码  → vbd 标点 / vjt 箭头 / vsx 数学 / vjm 平假名 …
v + 短码    → vdui ✓ / vno の / vpi π …
```

**选词规则**：分类候选出现后，数字键 = 选候选（1-9 对应候选位），空格 = 首个，翻页 = `+`/`-` 或 PgUp/PgDn。

| 输入法 | 触发方式 | 泰深对应 |
