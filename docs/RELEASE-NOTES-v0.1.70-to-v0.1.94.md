# 泰深输入法 v0.1.94 发布：从 0.1.70 到现在，我们把输入法重做了一遍

距离上次正式向大家介绍泰深输入法（`v0.1.70`），已经过去了 **25 个版本、近 300 次打磨**。

这段时间里，我们没有急着宣传，而是沉下心做了一件事：**把一款输入法从「能用」，真正打磨成你可以放心每天敲上万字的「主力工具」。**

现在的 **泰深输入法 v0.1.94**，依然坚持**纯自研、纯本地离线、零广告、零弹窗、不上传任何输入内容**。但无论是底层轻快度、长句准确度，还是软件兼容性和词库质感，都已经和 `0.1.70` 判若两物。

下面分三部分，带你看清这 25 个版本到底发生了什么变化：**以前没有的全新能力**、**原有功能的体验进化**，以及**我们在词库背后死磕的硬功夫**。

| :--- | :--- | :--- |

## 一、从 0 到 1：`0.1.70` 之前完全没有的新东西

如果你对泰深的印象还停留在 `0.1.70`，下面这些能力全都是这段时间全新长出来的：

1. **全新「超轻薄壳 + 独立后台服务」架构**
   以前每打开一个软件，都要在它里面塞进一整套输入法引擎；现在各个软件里只留一个 **0.71 MB** 的超轻薄壳，真正的词库和运算统一交给后台单一服务完成——软件开得再多也不重复吃内存，核心常驻内存压到了 **11 MB 左右**，几乎无感。
2. **本地整句语言模型上线，长句连打一口气出词**
   不用再两三个字一停顿地选词了。现在无论是完整长句，还是偷懒敲混拼（比如随手打 `zhongwshurf` 直接出「**中文输入法**」），都能顺畅连成通顺人话，连「在/再」「的/得/地」「他/她/它」这种高频同音字也能结合前后文智能分辨。
3. **智能前缀补全（字没敲完也能猜中整词）**
   音节还没打全时，候选栏就能提前补出高频整词，告别「少打一个字母就没词可选」的断层感；同时严格保护常用单字不被挤走，设置里也留了独立开关，开不开由你做主。
4. **32 位软件与老游戏全面打通**
   `0.1.70` 只有 64 位版本，遇到战网、部分老办公软件或 32 位游戏时根本切不出输入法。现在 **32 位 + 64 位全覆盖**，装上就能直接打字。
5. **Windows 任务栏搜索框、开始菜单、UWP 应用全面穿透**
   以前在系统任务栏搜索框或开始菜单里打字，候选窗经常被系统顶层界面挡住看不见；现在已完成高层窗口适配，系统各个角落都能稳稳弹出候选窗。
6. **三大主流输入法习惯「一键搬家」**
   换输入法最怕重新适应键位。现在设置里直接内置了三套一键预设，点一下三秒对齐老习惯：
   - **微软拼音风格**：横排 · 行内预编辑 · 微软双拼
   - **搜狗拼音风格**：横排 · 窗口拼音 · `,/.` 与 `-/=` 翻页
   - **小狼毫 / RIME 风格**：竖排 · 行内预编辑 · `[/]` 以词定字
7. **竖排候选窗**
   不再局限于横排候选，偏爱竖排阅读动线的朋友现在可以一键切换横/竖排布局。
8. **密码框与网址栏自动切英文 + 已上屏文字重选**
   点进密码框、浏览器地址栏时自动切为英文，不用再来回按 Shift；刚敲上屏的词如果选错了，选中它就能重新唤出候选修改。
9. **支持手动隔音符（`'`）与拼音中间改字**
   敲 `xi'an`、`yu'an` 可以随时用 `'` 明确切分音节；打长拼音发现前面少敲了字母，直接把光标移回中间就能插改，不用整串删掉重打。
10. **全新「词库与数据」页面 + 点选窗口配软件**
    设置中心从 7 页扩充至 **9 页**。想让终端/编辑器默认英文、聊天软件默认中文？现在不用自己去查进程名了，直接用「窗口拾取器」点一下屏幕上的软件窗口就能绑定。

## 二、全面进化：原有功能的痛点清零与手感打磨

除了新功能，我们把大家日常打字最容易皱眉的细节挨个推倒重磨了一遍：

- **彻底告别闪退与卡顿**
  - **根治 QQ 等软件切输入法闪退**：彻底解耦底层运行库依赖，不再被宿主软件自带的旧组件拖垮崩溃；
  - **修复游戏与特殊软件疑难杂症**：解决魔兽世界等游戏不弹候选窗、选词上屏后文字一直保持选中高亮、翻到第二页整页空白、切换窗口后第一个字候选窗乱飘到鼠标位置等问题；
  - **毫秒级跟手**：切换输入法首次激活不再卡顿，常用词单键响应约 **1 毫秒**，十几个字的长句也能稳稳控制在几毫秒内。
- **选词排序彻底重做：中文优先，不抢位、不添乱**
  - **中英混输改为「中文优先」**：以前打 `key` 前排全是英文，「可以」被挤到后面；现在只要有常用中文词，中文稳居前两位，英文留在第一页第 3 位随手可选；而打 `hello`、`python`、`npm` 等明确英文词时依然首位直出；
  - **纠错与模糊音不再「乱抢戏」**：补齐漏打字母纠错，同时把模糊音拆成 **9 组独立开关**（默认关闭），并且严格保证纠错词绝不抢走正常精确词的首位；打错成 `nihap` 也能稳稳纠出「你好」；
  - **词库里没有的新词短语，也能顺手拼出来（v0.1.94 最新打磨）**：遇到词库没收录的日常两三字口语组合或新说法，不再蹦出一堆生僻单字，而是自动组出通顺词句。
- **逐段选词顺滑得像大厂输入法**
  彻底重写了长句分段选词体验：选定前半段词后，已选汉字稳稳留在输入框、剩余拼音实时刷新后续候选，选完一次性干净上屏，按 `ESC` 还能整段撤回；以前翻页偶发往正文里漏进数字、已选字消失或重复上屏的毛病全部清零。
- **越用越懂你，而且「绝不会学歪」**
  - 近期常打的词迅速排到前面，很久不打的旧词自然淡出，不会一直霸占首屏；
  - **拒绝学进错词和半截拼音**：打一半的拼音、纠错临时选的词绝不再写进个人词库；升级时还会自动备份并帮你把历史脏数据清理干净；
  - **右键管理更精准**：在候选词上右键即可置顶、取消置顶、降权或删除，且提降权支持按当前拼音精准生效，不会因为置顶了一个词就在别的简拼下到处乱冒。
- **高分屏与标点细节处处顺心**
  - **数字后自动半角标点**：输入数字后紧跟 `,` `.` `:` 自动输出半角标点，写金额 `1,000`、版本号 `0.1.94`、时间 `12:30` 再也不用切英文；
  - **21 项界面细节打磨**：全面适配 2K/4K 高分屏，字迹锐利不截断、多行展开不漂移、自定义字体全面生效、滚轮翻页更顺手、补齐页码提示，点「恢复默认」也不会误删你配好的软件列表。

## 三、看不见的硬功夫：我们在词库上做的努力

很多人觉得输入法「聪明」或「笨」，一半在算法，另一半其实全在词库。这一个多月里，我们在独立词库工程上投入了大量精细活，只为让你少翻页：

1. **大补「每天真正在说的人话」：近万条日常口语与现代新词入库**
   传统开源词库往往书面语有余、口语不足，一打日常聊天就断成单字。我们专项补充了 **9,800+ 条高频口语表达与日常短语**（比如「我知道」「我们认为」「对吧」「没毛病」「先这样」「去哪儿」）、大量 **AI / 科技 / 职场现代词汇**，还新增了 **游戏专属领域词库**（含魔兽世界 860+ 常用词）。常用词表从 2,000 出头精选扩充至 **2,600+ 条**，并修正书面语词频倒挂——现在打「我们想去吃饭」，不会再尴尬地冒出「我们向去吃饭」。
2. **给词库做「深度大扫除」：清理 7,700+ 生僻废字与残缺碎片词**
   词库绝不是越大越好，混进来的生僻古字和跨词碎片越多，第一页候选就越乱。我们拿 37 万系统词库与 **186 万级多源词表**做了全量交叉体检与人工抽检（抽检准确率达 **98.75%**）：
   - 将 **1,100+ 个现代几乎不用的生僻古字/罕用扩展字**、以及 **6,600+ 条残缺碎片词**统一降权沉底（翻到最后依然能查到，但绝不再跑出来污染前几页）；
   - 同时补齐缺失音节的常用单字，并把被切碎的 **100+ 条高频长词**重新还原回库。
3. **多音字与易错读音逐条校准**
   专项补齐 **353 条常见多音字读音**，修正多处历史注音瑕疵与同音词权重失衡（例如让专有写法正常可打的同时，不抢走「神奇」「预案」等高频词的位置），解决「明明认识这个词、偏偏打不出来」的隐形卡点。
4. **38.6 万组上下文搭配大升级，砍掉 98% 的「假联想」噪声**
   我们将前后词搭配库从早期的五千多组一口气扩容到 **38.6 万组**，同时果断剔除了里面占绝大多数的「仅碰巧同现过一次」的偶然噪声——只保留真正高频自然的词语搭配。结果就是：打完「点击」接着敲 `shiyong`，「使用」稳稳排第一；而平时正常打字时，候选顺序再也不会因为偶然记录莫名乱跳。
5. **全自动词库防退化把关**
   建立起严格的词库自动体检机制，每次发版前自动核验简繁分流、字音对齐与真实长文章打字测试，301 项核心候选考试目前已做到 **100% 全绿通过**。

## 升级与安装说明

- **一键覆盖升级**：直接运行 `TaishenIME-Setup-0.1.94.exe` 即可完成升级（安装目录已统一至 `C:\Program Files\TaishenIME`）。你的个人词库与历史设置会自动保留，无需重新配置。
- **装完即用**：绝大多数桌面软件与游戏聊天安装完成后即可直接输入中文，无需额外折腾兼容脚本。
- **任务栏搜索框穿透（可选）**：当前阶段使用开发者自签证书。如果你想在 Windows 任务栏搜索框、开始菜单等系统顶层界面中正常弹出候选窗，可在安装向导或设置页「证书」中一键导入；选择跳过同样可以正常完成安装，不影响所有常规桌面软件的使用。
- **小提示**：升级完成后，全新引擎与词库会立即生效；已经打开的旧软件重启一次后，即可切换至最新的 0.71 MB 超轻薄壳模块。
