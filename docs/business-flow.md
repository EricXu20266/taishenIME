# 泰深输入法 — 核心数据流

## 主链路：按键 → 上屏

```
┌─────────────────────────────────────────────────────────────────┐
│ 阶段 1: 按键捕获                                                 │
│                                                                 │
│ 用户按下键盘 'z'                                                │
│   ↓                                                             │
│ Windows TSF 框架 → ITfKeyEventSink::OnKeyDown(keyCode=Z)       │
│   ↓                                                             │
│ tsf_module.cpp: 过滤非字母键（数字=选词, Space=提交, ESC=清空）   │
│   ↓ (字母键)                                                     │
│ engine_bridge.cpp → engine_process_key('z')                     │
└──────────────────────┬──────────────────────────────────────────┘
                       │ C FFI 边界
┌──────────────────────┴──────────────────────────────────────────┐
│ 阶段 2: 拼音累积                                                 │
│                                                                 │
│ Engine::process_key('z')                                        │
│   pinyin_buf: "" → "z"                                          │
│   candidates = dictionary::query("z")                           │
│                                                                 │
│ 重复: 'h' → "zh", 'o' → "zho", 'n' → "zhon", 'g' → "zhong"     │
│ 每次 query() 返回前缀匹配的候选词列表                              │
└──────────────────────┬──────────────────────────────────────────┘
                       │
┌──────────────────────┴──────────────────────────────────────────┐
│ 阶段 3: 词库查询                                                 │
│                                                                 │
│ dictionary::query("zhong")                                      │
│   → HashMap<prefix, Vec<(word, freq)>>                          │
│   → 前缀索引: "z", "zh", "zho", "zhon", "zhong" 都有条目        │
│   → ["中"(330), "中国"(500), ...] 按词频降序                     │
└──────────────────────┬──────────────────────────────────────────┘
                       │
┌──────────────────────┴──────────────────────────────────────────┐
│ 阶段 4: 候选窗口                                                 │
│                                                                 │
│ candidate_ui.cpp:                                               │
│   1. engine_get_candidate_count() → 候选数量                     │
│   2. for i in 0..count: engine_get_candidate(i, buf)            │
│   3. Skia Canvas 绘制候选列表                                    │
│      - 背景色 + 圆角                                             │
│      - 拼音串显示（顶部）                                        │
│      - 候选词列表（1-9 编号）                                    │
│   4. 窗口定位：光标下方                                          │
└──────────────────────┬──────────────────────────────────────────┘
                       │
┌──────────────────────┴──────────────────────────────────────────┐
│ 阶段 5: 选词上屏                                                 │
│                                                                 │
│ 用户按 Space → 选第一个候选词                                     │
│ 用户按 3 → 选第三个候选词                                         │
│   ↓                                                             │
│ engine_select_candidate(index, buf)                             │
│   → 返回提交文本（如 "中"）                                      │
│   → engine 内部自动 reset()                                      │
│   ↓                                                             │
│ tsf_module.cpp: ITfComposition 提交文本到目标应用                 │
│ candidate_ui.cpp: 隐藏候选窗口                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 支线链路

### 退格

```
用户按 Backspace
  → engine_backspace()
  → pinyin_buf.pop()
  → 新前缀重新 query()
  → 候选窗口刷新
```

### 中英文切换

```
用户按 Shift
  → engine 内部切换 mode: Chinese → English
  → 后续字母键直接透传到目标应用（英文模式）
  → 候选窗口隐藏
  → 再按 Shift 切回中文模式
```

### 清空

```
用户按 ESC
  → engine_reset()
  → 候选窗口隐藏
  → pinyin_buf 清空
```
