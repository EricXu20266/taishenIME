# SPEC: 以词定字（Root #2 #8，V0.2.24）

> 对应 ARCHITECT.md Root #2「输入引擎」+ Root #8「候选窗口」
> 关联 DEV-TRACKER: 0.2.24 以词定字（[ ] 键取首尾字）

---

## 一、需求

`[` 键取当前候选的第一个字上屏，`]` 键取最后一个字上屏。

**用户价值**：生僻字/易错字输入——先打词（如"垚"→"三土"打不出，打"垚峯"→ `]` 取峯），
或从词中提取单字（"招财进宝"→ `]` 取宝）。rime-ice 标配。

**合约**：
- 触发：候选存在时按 `[` / `]`
- `[` → 当前**选中候选**（高亮项，默认第 0 个）的首字符
- `]` → 当前选中候选的末字符
- 单字候选：`[` `]` 都上屏该字（首=末）
- 取字后重置状态（不学习用户词——取字非完整拼音词）
- 无候选时 `[` `]` 透传（应用输入方括号）
- 引擎侧实现，TSF 加按键映射

**不做**：
- 取中间某字（数字键选择多字）——rime 亦未提供，后续
- 跨候选页取字——仅当前选中项

## 二、数据模型

```
无新增状态字段——复用选中索引（m_selectedIndex / 候选第 0 项）
```

## 三、接口

### Engine（lib.rs）

```rust
/// 取当前选中候选的首/末字符（V0.2.24）
/// first=true 取首字符，false 取末字符；返回上屏文本，同时重置状态
/// 无候选/候选为空串 → None（平台层透传按键）
pub fn take_char(&mut self, first: bool) -> Option<String>;
```

### 行为细节

```
选中候选 = 当前页 index 0（未实现高亮翻页时取第 0 个）
取字：char::from 首个/最后一个 UTF-8 字符
不学习用户词（取字不是完整词）
简繁模式：取字后转繁体？——不转（生僻字场景以原字为准，与 select 一致简化）
```

### TSF（tsf_keyevent.cpp）

```
VK_OEM_4（[）：候选存在 → engine_take_char(first=true) → 上屏
VK_OEM_6（]）：候选存在 → engine_take_char(first=false) → 上屏
ShouldEatKey 同步：候选存在时吞 [ ]
```
